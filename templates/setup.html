First-time setup

ThreatLens is running. Configure the login before opening your analyst workspace.

Missing settings: {% for name in missing_settings %}{{ name }}{{ ', ' if not loop.last else '' }}{% endfor %}
  1. Open your Vercel project, then Settings → Environment Variables.
  2. Set SECRET_KEY to a long random secret and THREATLENS_PASSWORD to your demo password. Select Production and Preview.
  3. Redeploy the project, then sign in as analyst or your configured THREATLENS_USERNAME.

A VirusTotal API key is optional. Local scoring and all demonstration examples work without it. No database is needed.
